Chapter: Interrupts and Memory Management

1. Definition of Interrupt:
An interrupt is an asynchronous signal sent by hardware or software to the CPU indicating an event that needs immediate attention.
When an interrupt occurs, the CPU suspends its current execution, saves the program counter (PC) and processor status flags onto the kernel stack, and transfers execution to an Interrupt Service Routine (ISR).

2. Interrupt Types:
- Hardware Interrupts (Asynchronous): Generated by external I/O devices such as keyboard keystrokes, disk controllers, or timer ticks.
- Software Interrupts / Traps (Synchronous): Generated by software instructions, such as system calls or runtime exceptions (divide-by-zero, page faults).

3. Interrupt Vector Table (IVT):
The Interrupt Vector Table is an array of memory addresses located in protected kernel memory. Each entry holds the address of the corresponding ISR for a given interrupt vector number.

4. Virtual Memory and Paging:
Virtual memory is a memory management capability of an operating system that compensates for physical memory shortages by transferring data from RAM to disk storage.
Physical memory is divided into fixed-size contiguous blocks called frames. Logical address space is divided into blocks of the same size called pages (typically 4 KB or 4096 bytes).
- Address translation: The Memory Management Unit (MMU) uses the Page Table to translate virtual addresses (page number, offset) into physical addresses.

5. Calculations:
- For a 32-bit virtual address space with 4 KB page size:
  Number of pages = (2^32) / 4096 = 1,048,576 pages.
- Memory block allocation:
  If a file requires 2500 bytes and block size is 512 bytes, the number of required blocks is ceil(2500 / 512) = 5 blocks.
